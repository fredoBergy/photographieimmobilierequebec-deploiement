# Photographie immobilière Québec — déploiement

Ce dépôt public contient uniquement les fichiers publiables du site
`photographie-immobiliere-quebec.com`.

Le fichier `.cpanel.yml` déploie le contenu de `site-autonome/` vers le dossier
Web de production avec les permissions appropriées. Il conserve les dossiers
techniques déjà présents sur l’hébergement et ne supprime aucun fichier distant.

Les outils locaux, archives, clés, renseignements administratifs et fichiers de
prospection ne font pas partie de ce dépôt.
